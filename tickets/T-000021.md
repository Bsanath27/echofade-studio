## Goal
Prevent synchronous long-running download and metadata extraction calls in `/api/fetch-audio` from blocking the main FastAPI event loop thread, keeping the server completely responsive for other concurrent requests.

## Acceptance Criteria
- [x] Run `download_audio` in a background thread using `asyncio.to_thread`.
- [x] Run `extract_lyrics` in a background thread using `asyncio.to_thread`.
- [x] Prevent connection timeouts and request queuing on the local dev server.
