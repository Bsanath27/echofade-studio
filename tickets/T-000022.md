## Goal
Resolve rendering drift in the MoviePy engine (`video_composer.py`) on macOS where selected fonts (Helvetica Neue, Avenir Next, Futura, Didot, Baskerville) were mapped to incorrect system font files (like Trebuchet MS or DIN Alternate), causing exports to differ from the frontend preview.

## Acceptance Criteria
- [x] Update the font map in `video_composer.py` to point to the actual system `.ttc` or `.ttf` font files on macOS (e.g. `/System/Library/Fonts/HelveticaNeue.ttc`).
- [x] Maintain clean fallback behavior if a supplemental path doesn't exist on a specific macOS version.
