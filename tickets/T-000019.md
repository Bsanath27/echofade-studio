## Goal
Fix a bug in the Remotion rendering engine (`remotion_engine.py`) where all custom typography options chosen by the user (font family, font size, font color, position coordinates, stroke, shadows, and text transformations) were ignored during rendering and defaulted to a static Inter font layout.

## Acceptance Criteria
- [x] Forward all typography and positioning variables (`font_family`, `font_size`, `font_color`, `pos_x`, `pos_y`, `text_transform`, `stroke_width`, `stroke_color`, `shadow_offset`, `lyric_style`) in the Remotion props JSON output.
- [x] Declare these parameters in Remotion's composition Root type definitions (`Root.tsx`) and set matching defaults.
- [x] Bind the destructured props in the React layout (`LyricVideo.tsx` and `KineticText.tsx`) to inline element styles.
- [x] Position the text container dynamically using CSS `top` and `left` percentages driven by user settings.
